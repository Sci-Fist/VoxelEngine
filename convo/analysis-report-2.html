1. Race Condition: ActiveGenerations Counter

📁 FirstVoxel/Voxel/Core/World/VoxelWorldGeneration.cpp:267
Problem: Unsafe decrement of ActiveGenerations using raw -- operator. If CancelGeneration() fires callback AND background task completion fires, counter can go negative.

Impact: Generation limit bypass, memory exhaustion from unlimited async tasks. 
// UNSAFE - can go negative
S->ActiveGenerations--;

✅ Recommended Fix

// Use atomic decrement with bounds check
int32 OldValue = FPlatformAtomics::InterlockedDecrement(&S->ActiveGenerations);
checkf(OldValue >= 0, TEXT("ActiveGenerations went negative"));
