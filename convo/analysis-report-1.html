5. Serial Processing Bottleneck in Density Generation

📁 FirstVoxel/Voxel/Generation/VoxelGeneratorTask.cpp:250
Problem: Main density loop processes columns serially. SIMD parallelism only within each column (8 Z-values). This is the primary generation bottleneck.

Impact: Underutilizes multi-core CPUs, slower chunk generation. 
for (int32 FlatXY = 0; FlatXY < EffSize * EffSize; ++FlatXY)
{
    // Each column processed one at a time
    EvaluateColumn_AVX2(...); // SIMD within column only
}

✅ Recommended Fix

ParallelFor(EffSize * EffSize, [&](int32 FlatXY)
{
    EvaluateColumn_AVX2(...);
});
